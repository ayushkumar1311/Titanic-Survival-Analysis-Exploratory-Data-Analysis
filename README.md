# Titanic EDA & Survival Analysis using Python

An Exploratory Data Analysis (EDA) and predictive analysis project on the Titanic passenger dataset (`tested.csv`).

## Project Overview
This project performs data cleaning, feature engineering, and exploratory data analysis to uncover key demographic and socio-economic factors influencing passenger survival on the Titanic.

## Tools & Libraries Used
* **Language:** Python
* **Data Processing:** Pandas, NumPy
* **Data Visualization:** Seaborn, Matplotlib, Plotly
* **Machine Learning:** Scikit-Learn (Random Forest)

## Key Findings & Visualizations
* **Age Distribution & Survival:** Children (0–12 years) achieved higher survival rates (~48%) compared to young adults (~36%).
* **Family Size Impact:** Small family units (2–4 members) had significantly higher survival chances (up to 71.4%) compared to solo travelers (26.9%).
* **Social Honorifics & Class:** Ticket class and title extraction (`Mr`, `Mrs`, `Miss`, `Master`) served as strong predictors of survival outcomes.
